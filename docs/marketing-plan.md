# TimberPlay 机制科学玩具宣传方案

## 1. 破局定位

- **品牌名**：TimberPlay Lab
- **一句话卖点**：不是简单拼装，而是把 pinball、marble run、automata 等北美熟悉玩具做成能观察科学现象的机械实验。
- **核心转变**：
  - 从 “build a wooden toy” 转为 “build a mechanism, then discover why it works”。
  - 从静态模型转为可反复调参、挑战和复盘的 kinetic learning toy。
  - 从礼品属性转为“乐趣 + 工程结构 + 可见科学现象”的家庭实验室。
- **目标人群**：
  - 北美 25-45 岁父母，重视 screen-free play、STEM、科学启蒙和亲子项目。
  - 喜欢 maker culture、桌面机械、复古 arcade 和 puzzle engineering 的成年人。
  - 学校 STEM club、科学馆 gift shop、homeschool 社群和博物馆商店。

## 2. 产品机制打法

| 产品 | 玩具乐趣 | 揭示的科学/技术机制 | 内容钩子 |
| --- | --- | --- | --- |
| Wooden Pinball Machine | 弹射、反弹、计分挑战 | 能量转化、碰撞、摩擦、随机性、角度调参 | “为什么同一颗球每次路线不同？” |
| Marble Run Tower | 滚珠轨道挑战 | 重力势能、轨道曲率、速度控制、因果链 | “调高 1cm，滚珠会快多少？” |
| Mini Foosball | 家庭对战 | 杠杆、旋转动量、反应时间、碰撞角度 | “怎样踢出更稳定的斜线球？” |
| Rubber Band Racer | 赛车竞速 | 弹性势能、齿轮传动、轮胎摩擦、载荷 | “橡皮筋多绕几圈一定更快吗？” |
| Puzzle Safe | 解谜开锁 | 机构约束、齿轮比、组合逻辑、容错 | “密码盒为什么只在特定顺序打开？” |
| Mini Claw Machine | 抓取挑战 | 滑轮、张力、重心、夹爪几何 | “为什么夹得住却提不起来？” |

## 3. 首页与商品表达原则

1. **先给挑战，再给原理**
   - 文案格式：`挑战目标 → 可调变量 → 观察现象 → 背后原理`。
   - 示例：`调节 pinball 挡板角度，观察弹珠路线如何变化，理解碰撞和概率。`
2. **机制必须可见**
   - 页面图片/视频优先展示齿轮、轨道、杠杆、弹簧、滑轮，而不是只展示成品外观。
3. **玩法必须可复盘**
   - 每款产品配一张 experiment card：变量、预测、测试、记录。
4. **技术不是术语堆砌**
   - 用家庭能理解的语言解释：为什么快、为什么偏、为什么卡、为什么失败。

- **机制破局型**：“Not just a wooden puzzle. A working machine that teaches physics.”
- **现象观察型**：“Change one angle. Watch the whole pinball path change.”
- **亲子实验型**：“A weekend project that ends with a real science conversation.”
- **无屏挑战型**：“Screen-free play with gears, gravity, friction, and surprise.”
- **成人收藏型**：“A kinetic desk toy you can tune, test, and display.”
