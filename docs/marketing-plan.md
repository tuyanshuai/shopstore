# Wood Puzzle 创意木质玩具独立站宣传方案

## 1. 品牌定位

- **品牌名**：TimberPlay Lab
- **一句话卖点**：把北美家庭熟悉的经典玩具，做成可拼装、可展示、可亲子共创的木质机械模型。
- **核心品类**：
  - 木质 pinball machine 拼装套件。
  - marble run 滚珠轨道、桌面 arcade、机械齿轮 puzzle。
  - holiday gift、STEM project、family game night 场景礼盒。
- **目标人群**：
  - 北美 25-45 岁父母，关注 STEM、screen-free play 和亲子项目。
  - 喜欢模型、桌游、复古 arcade、maker culture 的成年人。
  - 礼品买家：生日、圣诞、Father's Day、返校季礼物。
- **价格带**：入门款 39-69 美元，主力套件 89-129 美元，高阶收藏款 149-199 美元。

## 2. 产品打法

1. **爆款引流：Wooden Pinball Machine Kit**
   - 北美用户认知高，复古 arcade 记忆强，适合 TikTok/YouTube 展示成品玩法。
   - 卖点：无胶拼装、真实弹珠回弹、可桌面竞技。
2. **亲子复购：Marble Run Builder**
   - 强调重组轨道、空间逻辑、家庭协作。
   - 可做扩展包和节日限定轨道。
3. **礼品款：Mini Arcade Basketball / Foosball Puzzle**
   - 对应常见 game room 玩具，适合 Father’s Day、生日和办公室礼物。
4. **高阶收藏：Gear Clockwork Puzzle**
   - 针对 maker、工程爱好者和模型玩家，突出机械结构与展示价值。
