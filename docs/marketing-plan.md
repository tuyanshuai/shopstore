# 冰箱贴独立站宣传方案

## 1. 品牌定位

- **品牌名**：Magnetica
- **一句话卖点**：把旅行、宠物、纪念日和厨房小确幸做成每天都能看见的小礼物。
- **目标人群**：
  - 20-35 岁喜欢家居装饰、手账、旅行纪念的女性用户。
  - 宠物主、情侣、婚礼回礼采购者。
  - 文旅商店、咖啡店、展会和小型品牌的定制采购方。
- **价格带**：单品 29-69 元，组合客单 99-199 元，企业/活动定制按量报价。

## 2. 核心产品打法

1. **引流款**：水果市集系列，低价高颜值，适合社媒种草和组合购买。
2. **利润款**：宠物头像定制冰箱贴，强调情绪价值和独一无二。
3. **场景款**：城市明信片、婚礼日期纪念贴，承接旅行纪念和礼品需求。
4. **B 端定制**：为咖啡店、文旅景点、展会品牌提供小批量定制。

## 3. 宣传节奏

### 上线前 7 天：种子内容蓄水

- 小红书/抖音发布 5 条短内容：
  - “冰箱门改造前后对比”
  - “宠物照片变冰箱贴全过程”
  - “旅行纪念品除了明信片还能买什么”
  - “婚礼回礼 50 元以内创意礼物”
  - “厨房小物提升幸福感清单”
- 设置首批内测福利：前 100 名订阅用户获得 `MAGNET10` 首单 9 折码。

### 上线第 1 周：集中转化

- 首页突出“3 件包邮”“定制 24 小时确认方案”“满 99 送随机贴”。
- 与 10-20 个小红书家居/宠物/旅行垂类 KOC 合作寄样。
- 建立用户晒图激励：晒单返 10 元无门槛券。
- 投放关键词：
  - 冰箱贴定制
  - 宠物周边定制
  - 旅行纪念品
  - 婚礼回礼小礼物

### 上线第 2-4 周：内容复用与私域沉淀

- 将用户晒图做成“本周冰箱门灵感”系列。
- 邮件/社群每周推送新品主题和组合搭配。
- 开放 B 端询价表单，面向咖啡店、展会、文旅账号私信触达。

## 4. 渠道策略

| 渠道 | 内容重点 | 转化动作 |
| --- | --- | --- |
| 小红书 | 家居改造、礼物清单、宠物定制过程 | 评论区引导搜索品牌名/领取优惠码 |
| 抖音 | 制作过程、开箱、冰箱门改造 | 视频挂独立站链接或私信自动回复 |
| Instagram/Pinterest | 高颜值场景图、系列套装 | 引流海外用户订阅新品 |
| 微信社群 | 新品预售、晒单返券 | 复购和组合购买 |
| SEO | 定制冰箱贴、城市纪念品、婚礼回礼 | 长尾关键词落地页 |

## 5. 广告素材方向

- **情绪价值型**：“把它贴在冰箱上，每天回家都能看见那只小猫。”
- **场景改造型**：“不用换厨房，换一组冰箱贴就能变可爱。”
- **礼物清单型**：“预算 50 元，送出比普通钥匙扣更有记忆点的礼物。”
- **B 端定制型**：“咖啡店、展会、文旅店都能做的小批量周边。”

## 6. 首月 KPI 建议

- 订阅用户：500+
- 首月订单：100 单
- 客单价：99 元以上
- 晒单内容：30 条以上
- B 端询盘：10 条以上

## 7. 后续优化

- 接入真实支付、物流查询、图片上传和订单后台。
- 对定制商品增加“上传照片 + 备注风格”流程。
- 为热门主题建立 SEO 落地页，例如“宠物冰箱贴定制”“婚礼回礼冰箱贴”。
- 根据订单数据扩展系列：城市地标、节日限定、星座、咖啡店周边。
